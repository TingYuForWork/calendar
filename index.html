如何常駐在 Windows 與 Mac 桌面？

Windows 電腦（Chrome / Edge）：
  1. 在瀏覽器右上角點擊「三個點選單 ⋮」。
  2. 選擇 「儲存與共用」 $\rightarrow$ 點擊 「安裝為應用程式」（或「建立捷徑」並勾選以視窗開啟）。
  3. 完成後，這款日曆就會像一般獨立軟體一樣常駐在您的工作列與桌面上！
蘋果電腦（Mac Safari / Chrome）：
  1. Safari：點擊上方選單列「檔案」$\rightarrow$ 「加入 Dock」。
  2. Chrome：點擊右上角選單 $\rightarrow$「儲存與共用」$\rightarrow$ 「安裝為應用程式」。
  3. 可隨時在 Dock 點開，獨立無網址列視窗，完全不干擾其他分頁。
👥 跨電腦共編提示： 只要兩台電腦右上角的「房間代碼（Room）」維持一致（例如：school-work-2026），任一端新增或修改行程，另一端在數毫秒內即時更新！
